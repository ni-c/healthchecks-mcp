## Fourteen tools, or seven

The tool list is not fixed. `HEALTHCHECKS_ALLOW_TOOLS=essential` narrows it to the
seven that cover the job end to end, and a name that matches nothing stops the
server instead of quietly leaving a tool out of `tools/list`.

![Listing the tools, narrowing them to the essential preset, and the startup abort a mistyped tool name produces](/demo.gif)

Recorded from `docs/demo.tape` with no credentials at all — the server starts
without an API key so that registries and inspectors can introspect it.
